Projects

  • 2026 - Present
    PVRD: Prior-guided Visual Residual Drafting for VLM Inference (Ongoing research)
    Developing speculative decoding that selects visual evidence beyond the language prior. The method adapts when and how much image information the drafter receives. Selected 21.3 of 576 patches on average, a 96.3% smaller budget, with 93.49% mean next-token distribution overlap in oracle experiments.
  • 2026 - Present
    Adaptive Modality Selection for Multimodal Diffusion (Ongoing research)
    Investigating predictive latent representations to decide when additional modality information justifies its computational cost during multimodal generation.
  • 2025
    CodeAlign: Code LLM Fine-tuning for Intelligent Code Understanding
    Fine-tuned DeepSeek-Coder-7B using QLoRA and DPO. Integrated Tree-sitter parsing, FAISS retrieval, and vLLM serving for repository-aware code explanation.
